# Тур по интерфейсу

Главное окно Foliant состоит из четырёх горизонтальных зон сверху вниз: триал-баннер
(если активен), строка меню, область вкладок с документом и строка состояния.

## Меню

Строка меню (`File`, `Tools`, `Edit`, `View`) — точка входа ко всем командам. Заголовки
локализуются (RU/EN) на лету.

- **File** — открыть документ, открыть недавний (список MRU), очистить список недавних;
  экспорты (annotated PDF, изображения страниц, закладки в sidecar и в PDF `/Outlines`);
  импорты (закладки, PDF outline); экспорт/импорт данных форм; операции над PDF
  (**Merge**, **Split into Files…**, **Extract Pages…**, **Insert Pages from PDF…**,
  **Add Watermark…**, **Add Header / Footer…**, **Bates Numbering…**, **Crop Pages…**,
  **Find and Redact…**), **Document Properties…** (метаданные /Info), **Number Pages…** (page labels),
  **Initial View…** (как документ открывается), **Attachments…** (вложенные файлы),
  **Named Destinations…** (именованные переходы), **Fonts…** (шрифты документа), **Links…** (ссылки),
  **XMP Metadata…** (XMP-пакет), **Remove JavaScript & Actions…** (очистка), **Print** (`Ctrl+P`) и выход.
- **Tools** — запустить OCR, отменить OCR, импортировать лицензию, открыть настройки.
- **Edit** — повернуть текущую страницу, удалить текущую страницу, переместить страницу
  вверх/вниз.
- **View** — выбор темы (Light / Dark / High Contrast), показать/скрыть аннотации,
  режимы масштаба (Fit Width / Fit Page / Actual Size), режимы просмотра
  (Single Page / Continuous / Two Page) и показать/скрыть полосу миниатюр.

## Вкладки документов

Документы открываются во вкладках (`TabControl`). Можно держать несколько открытых
документов одновременно и переключаться между ними мышью или горячими клавишами
(`Ctrl+Tab`, `Ctrl+1`…`Ctrl+9`, см. [Горячие клавиши](shortcuts.md)). Заголовок вкладки —
имя документа.

Содержимое активной вкладки разбито на до четырёх колонок: основная область страницы и
до трёх выдвижных панелей справа (поиск, аннотации, миниатюры).

## Область страницы и режимы просмотра

Центральная область показывает один из трёх режимов рендера (переключаются через меню
**View** или командами):

- **Single Page** — одна страница в прокручиваемой области; поверх неё накладываются
  слой аннотаций и подсветка результатов поиска.
- **Continuous** — вертикальный виртуализированный список страниц. Страницы рендерятся
  лениво при появлении на экране и освобождают память при прокрутке за пределы видимости,
  поэтому потребление памяти ограничено видимыми страницами.
- **Two Page** — фиксированные развороты из двух страниц рядом: `(1,2)`, `(3,4)`…
  Пункт меню **View → Separate Cover Page** («Обложка отдельно») показывает первую страницу
  одну, а развороты начинает со второй: `[1]`, `(2,3)`, `(4,5)`… Перелистывание (`PageDown`/
  `PageUp`) идёт целым разворотом.

Под рукой также режимы масштаба: **Fit Width**, **Fit Page** и **Actual Size**.

## Сайдбар поиска

Открывается по `Ctrl+F` (toggle). Содержит поле ввода запроса с кнопкой поиска,
три чекбокса опций (см. ниже), индикатор «идёт поиск» и список результатов. Каждый
результат показывает номер страницы и сниппет. Выбор результата переводит к нему;
совпадения подсвечиваются прямо на странице. Навигация по совпадениям — `F3` (вперёд)
и `Shift+F3` (назад).

Опции поиска (применяются и к списку результатов, и к подсветке на странице):

- **Match case** — учитывать регистр (по умолчанию выключено: `Foo` находит `foo`).
- **Whole word** — только целые слова (по умолчанию выключено: `cat` находит `category`).
- **Ignore diacritics** — игнорировать диакритику (по умолчанию выключено: при
  включении `cafe` находит `café`, `ежик` находит `ёжик`; реализация — NFD-нормализация
  и удаление комбинирующих знаков с обеих сторон сравнения).

## Watermark и колонтитулы (только для PDF)

Меню **File → Add Watermark…** открывает диалог, в котором задаются текст водяного
знака, размер шрифта (8–144 pt), прозрачность (5–100 %), угол поворота (-90°…+90°)
и цвет (R/G/B). После **OK** появляется диалог сохранения — оригинальный документ
не модифицируется, водяной знак накладывается на копию, выбранную пользователем.

Меню **File → Add Header / Footer…** работает аналогично: задаются тексты верхнего
и нижнего колонтитулов (хотя бы один обязателен), размер шрифта (6–24 pt) и цвет.
В тексте поддерживаются подстановки `{page}` (номер страницы, 1-based), `{total}`
(общее число страниц), `{filename}` (имя файла без пути), `{date}` (текущая дата
в формате `yyyy-MM-dd`). Пустое поле — соответствующая полоса не рисуется.

Оба пункта меню активны только когда в активной вкладке открыт PDF.

## Document Properties — метаданные (только для PDF)

Меню **File → Document Properties…** открывает диалог свойств документа. Поля Title / Author /
Subject / Keywords / Creator / Producer редактируемые, даты Created / Modified — только для чтения.
Пустое поле означает «не менять» (текущее значение источника сохраняется), поэтому открыть диалог
и нажать **OK** без правок — безопасно, существующие метаданные не стираются. Изменения пишутся в
копию документа, оригинал не модифицируется.

## Number Pages — метки страниц (только для PDF)

Меню **File → Number Pages…** задаёт page labels — отображаемые «номера» страниц в навигаторе,
отличные от физического индекса (как «Number Pages» в Acrobat). Нумерация описывается диапазонами:
каждый начинается с указанной страницы и имеет свой стиль — арабские `1, 2, 3`, римские `I/II/III`
или `i/ii/iii`, буквы `A/B/C` или `a/b/c`, либо «только префикс» без номера — плюс необязательный
префикс (например `A-` → `A-1`, `A-2`) и стартовый номер. Типовой кейс: предисловие `i, ii, iii`,
затем основной текст с `1, 2, 3`. Диалог показывает текущие диапазоны (с примером меток), позволяет
добавлять/удалять их, и сохраняет результат в копию PDF (`/PageLabels`); оригинал не меняется.

## Initial View — как документ открывается (только для PDF)

Меню **File → Initial View…** задаёт, как просмотрщик открывает документ (вкладка «Initial View» в
Acrobat): раскладку страниц (одна / непрерывно / разворот, нечётные слева или справа), активную
навигационную панель (закладки / миниатюры / слои / вложения / полный экран) и UI-флаги (скрыть
панель инструментов или меню, подогнать/центрировать окно, показывать заголовок документа в
заголовке окна). Значение «по умолчанию» оставляет выбор за просмотрщиком (ключ не пишется).
Настройки сохраняются в копию PDF (`/PageLayout`, `/PageMode`, `/ViewerPreferences`); оригинал не
меняется. Эти настройки — подсказки просмотрщику: их соблюдение зависит от приложения, открывающего
файл.

## Insert Pages from PDF (только для PDF)

Меню **File → Insert Pages from PDF…** вставляет все страницы другого PDF в текущий документ.
Сначала выбирается PDF-источник, затем — позиция вставки: «после страницы N» (0 = перед первой
страницей, число страниц = в конец). Результат сохраняется в новый файл; оригинал не меняется.
Для частичной выборки страниц используйте **Extract Pages…** на источнике, затем вставку.

## Attachments — вложенные файлы (только для PDF)

Меню **File → Attachments…** открывает список файлов, встроенных в PDF (имя, размер, описание).
В диалоге можно: **Add…** — выбрать файл и сохранить новый PDF с этим вложением; **Extract…** —
сохранить выбранное вложение на диск (бинарно точно, со снятием Flate-сжатия при необходимости);
**Remove** — сохранить новый PDF без выбранного вложения. Add/Remove создают копию (оригинал не
меняется), Extract только читает. Каждое действие выполняется по очереди (диалог открывается заново
для следующего).

## XMP Metadata (только для PDF)

Меню **File → XMP Metadata…** показывает XMP-пакет документа (XML) в редактируемом поле. XMP —
расширенные метаданные (как «Additional Metadata» в Acrobat); они нужны для PDF/A и documents-of-record.
Если пакета нет, поле заполняется минимальным шаблоном. После правки **Save As…** записывает копию PDF
с обновлённым `/Metadata`-потоком; оригинал не меняется. Это «сырой» XMP-редактор для опытных
пользователей — структура XML на вашей ответственности.

## Remove JavaScript & Actions (только для PDF)

Меню **File → Remove JavaScript & Actions…** сканирует документ на встроенный JavaScript и
автодействия (Acrobat «Sanitize») и показывает находки: скрипт при открытии (`/OpenAction`),
документ-уровневые скрипты (`/Names → /JavaScript`) и действия при закрытии/сохранении/печати
(`/AA`). Кнопка **Remove & Save As…** сохраняет очищенную копию без них; безопасный `GoTo`-переход
при открытии (не-JS) сохраняется, как и прочие вложения/именованные назначения. Оригинал не меняется.

## Named Destinations (только для PDF)

Меню **File → Named Destinations…** показывает именованные точки перехода документа (имя → страница) —
на них ссылаются внутренние ссылки и закладки (Acrobat «Destinations»). Читаются обе формы хранения
(современная `/Names/Dests` и устаревшая `/Dests`). В форме можно задать имя и целевую страницу и
нажать **Add / update** (создать/заменить), либо выбрать запись и **Remove selected**. Изменения
пишутся в копию (современная форма `/Names/Dests`); оригинал не меняется. Имя, существующее только в
устаревшей `/Dests`, читается, но не удаляется (MVP-ограничение).

## Fonts (только для PDF)

Меню **File → Fonts…** показывает список шрифтов документа (Acrobat «Document Properties → Fonts»):
имя, подтип (Type1 / TrueType / Type0 …) и встроен ли шрифт. Встраивание важно для корректной печати
и соответствия PDF/A. Только просмотр — документ не изменяется.

## Links (только для PDF)

Меню **File → Links…** показывает гиперссылки документа: для каждой — страница-источник и цель
(внешний URI или номер страницы для внутренних переходов). Ссылки на именованные назначения
показываются как «другая цель» (резолвинг имён — вне MVP). Только просмотр — документ не изменяется.

## Экспорт закладок в PDF (только для PDF)

Меню **File → Export Bookmarks to PDF…** встраивает текущие закладки документа в структуру PDF
`/Outlines` (в отличие от sidecar-экспорта «Export Bookmarks», который пишет внешний файл). После
этого закладки видны в Acrobat и любом стороннем просмотрщике; вложенность сохраняется и переживает
обратный round-trip через **File → Import PDF Outline**. Пункт активен, когда открыт PDF и у него
есть хотя бы одна закладка.

## Печать

Меню **File → Print…** или `Ctrl+P` открывает системный диалог печати Windows (выбор принтера и
диапазона страниц). Печать document-neutral: работает для PDF, изображений, EPUB/FB2/MOBI и DjVu —
страницы рендерятся через общий механизм рендеринга `IDocument.RenderPageAsync`. Сейчас одна
страница печатается на один лист в натуральном размере (scale-to-fit и N-up — Phase 2 follow-up).

## Открытие защищённых паролем PDF

При открытии зашифрованного (password-protected) PDF появляется диалог ввода пароля; при неверном
пароле он показывается повторно с баннером ошибки, **Cancel** просто закрывает попытку. Расшифровку
(AES/RC4) выполняет PDFium — Foliant лишь передаёт пароль. Это касается **открытия** на чтение;
шифрование при сохранении (write) пока не реализовано (Phase 3).

## Палитра инструментов аннотирования

Над областью страницы расположена панель инструментов (toolbar). Каждая кнопка
включает соответствующий инструмент; повторный клик по активной кнопке выключает
его (режим просмотра). Клавиша **Esc** также сбрасывает активный инструмент.

Доступны все 11 типов аннотаций, сгруппированные по способу создания:

- **Drag-rect** (нарисуйте прямоугольник протягиванием мыши): выделение (Highlight),
  подчёркивание (Underline), зачёркивание (Strikethrough), прямоугольник (Rectangle),
  эллипс (Ellipse), штамп (Stamp).
- **Две точки** (протяните от начала к концу): линия (Line), стрелка (Arrow).
- **От руки** (рисуйте, удерживая кнопку): Freehand.
- **Многоугольник** (Polygon): кликайте по вершинам, двойной клик замыкает контур;
  Esc отменяет незавершённый контур.
- **Один клик**: заметка (Sticky Note) ставится в точке клика.

Рядом — палитра из 7 цветов: выбранный цвет применяется ко всем новым аннотациям.
Для штампа появляется поле с готовыми надписями (`APPROVED` / `REJECTED` / `DRAFT`) или
произвольным текстом, а также кнопка **«Pick image…»** — выбранное изображение
(PNG/JPG) становится внешним видом штампа (надпись сохраняется как fallback для
программ без поддержки image-штампов). Кнопка **«Clear image»** возвращает текстовый штамп.

Инструменты работают во всех трёх режимах просмотра (одна страница, непрерывный,
разворот) — аннотация создаётся на той странице, по которой проведено действие.

## Сайдбар аннотаций

Панель «All Annotations» (переключается через **View → Annotations**) показывает все
аннотации документа, сгруппированные по страницам, с кнопкой **Export** и счётчиком
общего количества. Экспорт поддерживает форматы JSON, XFDF, FDF и Markdown; через
**File → Export Annotated PDF…** аннотации встраиваются в новый PDF как нативные
объекты `/Annots` (highlight/underline/strikeout/note/ink/square/circle/stamp).
Заметку можно также быстро создать двойным кликом по странице без выбора инструмента.

## Полоса миниатюр

Узкая панель справа (переключается через **View → Thumbnails**) показывает миниатюры
страниц. Миниатюры рендерятся лениво при появлении и кэшируются. Клик по миниатюре
переводит к странице. Полосу можно использовать для **переупорядочивания страниц
перетаскиванием** (drag-and-drop): перетащите миниатюру на новую позицию, и страница
переместится в документе.

## Строка состояния

Внизу окна: слева — общее сообщение состояния; справа — статус OCR, информация о текущей
странице и текущий масштаб в процентах.

## Ограничения текущей альфы

PDF, DjVu и изображения рендерятся полноценно: страницы выводятся как растровая графика
со всеми визуальными элементами. EPUB, FB2 и MOBI на Phase 1 открываются и индексируются
для поиска и FTS, навигация по оглавлению и разделам работает, но сама страница рисуется
белым холстом — текст виден только через сайдбар поиска и навигацию. Полноценный
визуальный рендер EPUB/FB2/MOBI запланирован на Phase 2 (треки D6b и D8b).
