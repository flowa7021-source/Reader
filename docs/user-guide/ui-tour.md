# Тур по интерфейсу

Главное окно Foliant состоит из четырёх горизонтальных зон сверху вниз: триал-баннер
(если активен), строка меню, область вкладок с документом и строка состояния.

## Меню

Строка меню (`File`, `Tools`, `Edit`, `View`) — точка входа ко всем командам. Заголовки
локализуются (RU/EN) на лету.

- **File** — открыть документ, открыть недавний (список MRU), очистить список недавних, выход.
- **Tools** — запустить OCR, отменить OCR, импортировать лицензию, открыть настройки.
- **Edit** — повернуть текущую страницу, удалить текущую страницу, переместить страницу
  вверх/вниз.
- **View** — выбор темы (Light / Dark / High Contrast), показать/скрыть аннотации,
  режимы масштаба (Fit Width / Fit Page / Actual Size), режимы просмотра
  (Single Page / Continuous / Two Page) и показать/скрыть полосу миниатюр.

## Вкладки документов

Документы открываются во вкладках (`TabControl`). Можно держать несколько открытых
документов одновременно и переключаться между ними мышью или горячими клавишами
(`Ctrl+Tab`, `Ctrl+1`…`Ctrl+9`, см. [Горячие клавиши](shortcuts.md)). Заголовок вкладки —
имя документа.

Содержимое активной вкладки разбито на до четырёх колонок: основная область страницы и
до трёх выдвижных панелей справа (поиск, аннотации, миниатюры).

## Область страницы и режимы просмотра

Центральная область показывает один из трёх режимов рендера (переключаются через меню
**View** или командами):

- **Single Page** — одна страница в прокручиваемой области; поверх неё накладываются
  слой аннотаций и подсветка результатов поиска.
- **Continuous** — вертикальный виртуализированный список страниц. Страницы рендерятся
  лениво при появлении на экране и освобождают память при прокрутке за пределы видимости,
  поэтому потребление памяти ограничено видимыми страницами.
- **Two Page** — фиксированные развороты из двух страниц рядом: `(1,2)`, `(3,4)`…
  Пункт меню **View → Separate Cover Page** («Обложка отдельно») показывает первую страницу
  одну, а развороты начинает со второй: `[1]`, `(2,3)`, `(4,5)`… Перелистывание (`PageDown`/
  `PageUp`) идёт целым разворотом.

Под рукой также режимы масштаба: **Fit Width**, **Fit Page** и **Actual Size**.

## Сайдбар поиска

Открывается по `Ctrl+F` (toggle). Содержит поле ввода запроса с кнопкой поиска,
индикатор «идёт поиск» и список результатов. Каждый результат показывает номер страницы
и сниппет. Выбор результата переводит к нему; совпадения подсвечиваются прямо на
странице. Навигация по совпадениям — `F3` (вперёд) и `Shift+F3` (назад).

## Сайдбар аннотаций

Панель «All Annotations» (переключается через **View → Annotations**) показывает все
аннотации документа, сгруппированные по страницам, с кнопкой **Export** и счётчиком
общего количества. Поддерживаются аннотации трёх типов — выделение (highlight), заметка
(note) и рисование от руки (freehand). Заметки создаются двойным кликом по странице через
слой аннотаций.

## Полоса миниатюр

Узкая панель справа (переключается через **View → Thumbnails**) показывает миниатюры
страниц. Миниатюры рендерятся лениво при появлении и кэшируются. Клик по миниатюре
переводит к странице. Полосу можно использовать для **переупорядочивания страниц
перетаскиванием** (drag-and-drop): перетащите миниатюру на новую позицию, и страница
переместится в документе.

## Строка состояния

Внизу окна: слева — общее сообщение состояния; справа — статус OCR, информация о текущей
странице и текущий масштаб в процентах.
